A [make.fun](https://make.fun/competitions/u-markk-st-one-line-no-deadline-met-6adc00ce) entry for the **One Line, No Deadline Met** competition.

## The entry

`main.ts` writes a single-line joke excusing a missed deadline to `/output/entry.txt`:

> I didn't miss the deadline — I just let it cross the finish line first so it wouldn't feel bad about beating me.

The deadline is reframed as a race opponent, and the narrator takes a
fake-sportsmanlike loss on purpose — letting the deadline "win" so it won't
feel bad. The excuse is absurd (deadlines don't have feelings), the punch
lands on the last word, and it reads like something a cornered person would
actually blurt out. No dog ate anything, nobody blames the Wi-Fi.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Deterministic, standard library only. The program enforces the competition
gate in code: the entry must be a single line of 1–200 characters, not blank.
